## Goal

Build SQL ability from fundamentals to advanced interview-level query solving.

The goal is not to memorize queries.

The goal is to:

- understand relational query logic
- recognize recurring SQL patterns
- translate requirements into queries
- choose appropriate SQL constructs
- handle edge cases correctly
- solve unfamiliar SQL interview problems
